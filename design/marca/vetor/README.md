# Logo em vetor

Aprovada em 2026-10-23. Estes SVGs são a fonte oficial da marca; os PNGs são prévias geradas a partir deles.

| Arquivo             | Uso                                         |
| ------------------- | ------------------------------------------- |
| `simbolo.svg`       | Símbolo sozinho (anel e pessoas)            |
| `logo.svg`          | Logo completa sobre fundo claro             |
| `logo-negativa.svg` | Logo completa sobre fundo azul ou escuro    |
| `icone-app.svg`     | Ícone do app (iOS e Android)                |

Os textos estão convertidos em curvas, então não dependem das fontes Fredoka e Montserrat (OFL) instaladas.
